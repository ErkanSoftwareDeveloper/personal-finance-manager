## Project Scope

### Version 1 — Completed

#### Core Features

* User registration
* Duplicate username validation
* Secure password hashing with bcrypt
* OAuth2-compatible user login
* JWT-based authentication
* View authenticated user profile
* Add income transactions
* Add expense transactions
* View authenticated user's transactions
* View authenticated user's balance
* User-specific protected endpoints
* SQLAlchemy CRUD layer
* MySQL database integration
* Environment-based configuration
* Swagger API documentation

### Version 2 — Planned

* Update transactions
* Delete transactions
* Transaction date support
* Filter transactions by date, category, or type
* Pagination
* Category management
* Monthly income and expense reports
* Automated tests
* Docker support
* Alembic database migrations
* Frontend integration
